# size

Legt die Foliengröße fest. Standard ist 1920 × 1080 (16:9). Alle Koordinaten beziehen sich auf
diese Größe; beim Export nach PPTX und PDF wird das Seitenverhältnis übernommen.

```text
size 1920x1080      // 16:9
size 1440x1080      // 4:3
```

## Parameter

### größe
- Typ: Größe
- positional
- erforderlich

Breite × Höhe in der Form `1920x1080`.
